(1) PlmSsoDemo.SmartClientのプロパティ画面「Debug」において「コマンドライン引数」に値が設定されている場合は消去しておく。

(2) ブラウザのプライベートウインドウを開き、 https://sp.plm-lab.local/PLM/Default.aspx にアクセスする。（SSO認証を通過し、PLMメイン画面を表示する）

(3) Visual Studioで"w3wp.exe"プロセスにアタッチする

(4) PLMメイン画面の「SmartClientを起動」ボタンを右クリックし、リンクURLを取得する

(5) Visual Studioで PlmSsoDemo.SmartClient を右クリックし、Debug → Start New Instance でデバッグ起動する。ここで表示されるウインドウに(4)でコピーしたリンクURLを貼り付ける。

なお、リンクURLは１回のみ有効、かつ有効期限は60秒。

有効期限切れになった場合はPLMメイン画面の「(1)ブラウザ画面(.aspx)」の項の「この画面を再読み込み（新しい引換券を取得）」をクリックすることで引換券を更新する。
