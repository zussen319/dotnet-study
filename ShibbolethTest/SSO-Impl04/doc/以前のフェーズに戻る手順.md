ClickOnce の性質上、**古いバージョンだけを選んで起動する仕組みはありません**。ただし、フォルダを分けて進めてこられたので、確実な方法があります。

## 推奨：該当フェーズのフォルダから再発行する

`SSO-Impl02`〜`SSO-Impl04` と各フェーズのソースが残っているはずなので、**戻りたいフェーズのフォルダで発行し直す**のが最も確実です。

たとえばフェーズ3の状態に戻る場合は、次の手順になります。

1. IIS マネージャーで、仮想ディレクトリ `/PLM/smartclient` の物理パスを **`SSO-Impl03` 側の発行先**に変更
2. アプリケーション `/PLM` の物理パスも **`SSO-Impl03\PlmSsoDemo\PlmSsoDemo.Web`** に変更
3. ブラウザで `https://sp.plm-lab.local/PLM/Default.aspx` を開いて起動

**サーバー側とクライアント側は対で動く**ので、両方を同じフェーズに揃えるのが要点です。フェーズ4のサーバーにフェーズ3のクライアントを繋いでも、意味のある確認にはなりません。

## ただし1点、注意が必要です

**ClickOnce はバージョンが同じだと再ダウンロードしません。** 各フェーズで発行バージョンが自動的に上がっていた場合、古い方のバージョン番号が小さいため、キャッシュに新しいものが残っていると「更新不要」と判断されて古い方が起動しない可能性があります。

そのため、フォルダを切り替えたら**先にキャッシュを消す**のが確実です。

```
rundll32 dfshim CleanOnlineAppCache
```

これで ClickOnce のオンラインアプリのキャッシュがすべて消え、次回起動時に配置マニフェストから改めてダウンロードされます。オンライン専用なので、消しても再取得されるだけで実害はありません。

## 手軽に済ませたい場合

コードの動作だけを確認したいのであれば、**ClickOnce を使わずに VS から直接実行**する方が簡単です。

該当フェーズの `PlmSsoDemo.SmartClient` プロジェクトを VS で開き、プロパティ →「デバッグ」→「コマンドライン引数」に引換券を指定して F5 で実行します。

```
--ticket=＜ブラウザ画面に表示された引換券＞
```

ただし引換券は画面に**先頭8文字しか表示されない**ため、全体を取得する必要があります。その場合は、ブラウザで「SmartClient を起動」リンクを**右クリック →「リンクのアドレスをコピー」**すると、`?ticket=` 以降に完全な値が入っています。60秒で失効するので、コピーしたら手早く実行してください。

## どのフェーズの何を確認されますか

もし特定の挙動や設計判断を再確認したいということであれば、**該当フェーズの README とコードから説明することもできます**。環境を切り替えずに済むぶん手軽なので、目的によってはそちらの方が早いかもしれません。
